About.

I sit at the intersection of engineering, SEO, and conversion optimization.

Most "SEO experts" can't write code. Most developers don't understand search or conversion strategy. I do both — which means I can diagnose why your site underperforms AND fix it myself.

My background: I started in web marketing, got obsessed with why some sites convert and others don't, then went deep on the technical side. Now I run a consultancy where I help companies optimize performance, fix technical SEO issues, and run data-driven A/B tests.

What I Do.

Technical SEO Audits

Comprehensive analysis of crawlability, indexation, Core Web Vitals, and technical debt. You get a prioritized roadmap, not a 200-page PDF you'll never read.

Typical outcome: Clear action plan with ROI estimates for each fix.

Web Performance Optimization

Slow sites lose rankings and conversions. I identify what's actually causing the bloat — usually JavaScript from marketing tools — and fix it without breaking functionality.

Typical outcome: 40-60% improvement in load times, green Core Web Vitals.

Conversion Rate Optimization

Data-driven A/B testing and UX improvements. I don't guess — I use analytics to find friction points, build test variations, and measure what actually moves the needle.

Typical outcome: Measurable conversion lifts backed by statistical significance.

Webflow Development

Custom Webflow builds with clean architecture, Memberstack for user management, Stripe for payments, and performance baked in from the start.

Typical outcome: Fast, maintainable sites that rank and convert.

International SEO & Localization

Expanding to new markets? I handle hreflang implementation, localized content strategy, and technical setup so you don't tank your existing rankings in the process.

Typical outcome: Clean international architecture, no duplicate content issues.
